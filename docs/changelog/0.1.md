# 0.1 release line

Status: open

## Established

- Workspace, basic CI, one formatting hook, and release helpers.
- Separate the Rust 1.97.1 development pin from the Rust 1.91.0 MSRV check.
- Pure timer-control state machine and thin `ic-cdk-timers` boundary.
- Explicit documentation that the scaffold is not yet a recovery watchdog.

## Next

- Specify bounded identity, policy, state, outcome, measurement, and snapshot
  value types, including ordering and serialization expectations.
- Implement a pure serial registry with duplicate detection and deterministic
  snapshots before connecting it to the platform boundary.
- Add measured execution and the non-watchdog scheduling policies.
- Compose synchronous restore participants without competing lifecycle macros.
- Add PocketIC evidence for the recovery and isolation cases in the
  architecture note.
